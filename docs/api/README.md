# API docs

API specifications for Opportunities Hub (Aukas).

| File | Contents |
|---|---|
| [`rest-spec.md`](./rest-spec.md) | Full REST API specification — auth, users, opportunities, bookmarks, applications, admin |
| [`openapi.yaml`](./openapi.yaml) | Machine-readable OpenAPI 3.0 spec — import into Swagger UI or Postman to explore the API interactively |

The narrative spec (`rest-spec.md`) is the source of truth. The OpenAPI YAML is generated from it — if the two ever disagree, update the YAML to match.
