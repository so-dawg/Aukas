# Backend

Node.js + Express API for Opportunities Hub.

## Structure
- `src/routes/` — Express route definitions (URL → controller)
- `src/controllers/` — request handlers and business logic
- `src/models/` — database access / query functions
- `src/middleware/` — auth, error handling, logging, validation
- `src/db/` — PostgreSQL connection pool and helpers
- `migrations/` — SQL migration files (versioned, e.g. `001_create_users.sql`)
- `tests/` — backend tests
